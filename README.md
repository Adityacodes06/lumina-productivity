# Lumina 🌌

Lumina is a premium, minimalist productivity suite designed with aesthetics and focus in mind. Built using modern web technologies, it features a glassmorphism interface with smooth animations and high-precision timing tools.

## Features ✨

- **Digital Clock**: Real-time display with neon glow aesthetics and adaptive dating.
- **Countdown Timer**: Precision timer for focus sessions or tasks.
- **Professional Stopwatch**: Lap-tracking stopwatch for timing workflows with millisecond accuracy.
- **Glassmorphism UI**: High-end visual design with animated background blobs and blurred overlays.

## Tech Stack 🛠️

- **HTML5**: Semantic structure.
- **Vanilla CSS**: Custom design system, glassmorphism, and keyframe animations.
- **JavaScript**: Core logic for timing and view management.

## Installation 🚀

Simply open `index.html` in any modern browser to start using Lumina. No installation or dependencies required.
